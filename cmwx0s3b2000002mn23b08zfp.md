In my previous article, [Power-Up #8: Three Months with Amp Orb](https://blog.productsway.com/power-up-8-three-months-with-amp-orb-from-cli-to-cloud-agents), I shared my experience moving from CLI-based coding to cloud agents.

With Amp, Claude Model Routing and smolvm, we can build a personal AI coding environment using hardware and subscriptions we already have.

## 1\. The idea

Instead of paying for another cloud coding agent, we combine three components:

- **Amp:** Agent orchestration, thread management and remote access.
- **Claude:** AI inference through an existing subscription.
- [**smolvm**](https://github.com/smol-machines/smolvm)**:** Lightweight, isolated Linux environments running on macOS.

The goal is to separate orchestration, inference and execution while keeping additional costs close to zero.

## 2\. Install smolvm

[smolvm](https://github.com/smol-machines/smolvm) provides lightweight Linux microVMs on your Mac.

```bash
brew install smol-machines/tap/smolvm
```

Unlike running coding agents directly on your host machine, a microVM provides an additional isolation boundary for executing code, installing dependencies and running tests.

## 3\. Install Amp on your Mac

Install Amp directly on macOS, not inside the virtual machine.

```bash
curl -fsSL https://ampcode.com/install.sh | bash
```

Sign in to your Amp account:

```bash
amp login
```

Your Mac becomes the host for managing your coding agents.

## 4\. Bring your own Claude subscription

This is where things get interesting.

Go to [Amp Settings](https://ampcode.com/settings) and configure Model Routing:

1. Open Model Routing.
2. Add your Claude subscription.
3. Authenticate your account.
4. Select the connected provider for inference.

![](https://cdn.hashnode.com/uploads/covers/56ee654dbcca2d711e191e2a/884ea037-cb4d-409b-bd77-4ea5b3078b78.png align="center")

Instead of purchasing additional inference credits, you can leverage your existing Claude subscription, subject to its usage limits. Here is my **Model Selector** for the reference.

![](https://cdn.hashnode.com/uploads/covers/56ee654dbcca2d711e191e2a/9213a028-f1a0-47b7-8941-246498c2aec2.png align="center")

## 5\. Turn your Mac into a personal coding cloud

Amp supports self-hosted runners, allowing you to use your own computing resources instead of paying for hosted execution.

The next step is to integrate the runner with **smolvm** so that coding tasks can execute inside isolated environments.

The target architecture is:

```text
Amp Web / Mobile / CLI
         |
    Amp Control Plane
         |
    Model Routing ------ Claude
         |
     Your Mac
         |
    Amp Runner
         |
      smolvm
         |
   Build / Test / Code
```

Imagine starting a coding task from your iPhone while having lunch, letting your Mac execute it, and reviewing the changes when you return.\
\
Make sure you change your Orbs setting to your self-hosted: e.g m1-mac-vm.

![](https://cdn.hashnode.com/uploads/covers/56ee654dbcca2d711e191e2a/890f28c7-b896-487b-b8cd-44e8cf764d82.png align="center")

You get the convenience of a cloud coding agent while maintaining control over your execution infrastructure.

## 6\. What does it cost?

| Component | Additional cost |
| --- | --: |
| Amp free account | $0 |
| Self-hosted runner | $0 |
| smolvm | $0 |
| Existing Claude subscription | $0 |
| Existing Mac | $0 |
| **Target additional service cost** | **$0/month** |

Of course, this does not mean unlimited free AI inference. Claude subscription limits, electricity and optional paid Amp features still apply.

However, if you already own a Mac and subscribe to Claude, you potentially have everything you need.

## 7\. Beyond coding agents

What excites me about this approach is not simply saving money.

It is the ability to build a modular AI software factory where each component can evolve independently:

- Replace the model provider without changing the execution environment.
- Create isolated environments for different projects.
- Run multiple coding tasks in parallel.
- Experiment with different agent workflows.
- Maintain control over infrastructure and development environments.

The future of AI coding may not require another expensive, all-in-one subscription. Instead, we can compose existing tools into a system that works for us.

## Final thoughts

Cloud coding is more about accessibility than where the computation happens.

Your Mac can become your personal coding cloud. Amp can provide the orchestration layer, Claude can provide the intelligence, and smolvm can provide the isolated execution environment.

The remaining piece I am exploring is the integration between Amp runners and smolvm to make isolated execution seamless.

**Bring your own compute. Bring your own model. Build your own AI coding cloud.**
